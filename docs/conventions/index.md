# Convenções

Regras que guiam uma decisão no código do dailly.

* [Arquitetura](/conventions/architecture.md) - a forma do sistema hoje, o desenho, e o porquê de cada decisão (as antigas ADRs)
* [Módulos](/conventions/modules.md) - como um módulo de produto novo entra, nos dois lados, e o que os testes cobram dele
* [Versão](/conventions/versioning.md) - SemVer: o `VERSION` da raiz, o `CHANGELOG.md` e quando subir cada número
* [OKF neste bundle](/conventions/okf.md) - tipos, campos e regras de escrita destes docs
